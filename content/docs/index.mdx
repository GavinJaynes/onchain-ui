## What is onchain-ui?

onchain-ui is an open source [shadcn registry](https://ui.shadcn.com/docs/registry) of web3 UI components.
The components use [viem](https://viem.sh) for EVM addresses and identity resolution, [wagmi](https://wagmi.sh) for wallet connections, and Tailwind CSS for styles.

Install a component to add its source code to your app:

<InstallTabs command="shadcn add @onchain-ui/address-display" />

## How the components work

Edit the installed files to change styles or behavior. Components use shadcn buttons, menus, and tooltips, so they share your app's theme.

Pass balances, prices, and token metadata as props. `AddressIdentity` can resolve ENS names and Basenames, and `ConnectWallet` handles connections through wagmi. See [Configuration](/docs/configuration) to set your EVM chains and RPC endpoints.

## Getting started

onchain-ui is listed in the [shadcn registry directory](https://ui.shadcn.com/registries), so the `@onchain-ui` namespace works with no setup. Install the [shadcn CLI](https://ui.shadcn.com/docs/cli) if you haven't already, then add any component:

<InstallTabs command="shadcn add @onchain-ui/address-display" />

<InstallTabs command="shadcn add @onchain-ui/token-logo" />

<InstallTabs command="shadcn add @onchain-ui/asset-row" />
